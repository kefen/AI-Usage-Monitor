安装与首次打开

此测试版未经 Apple 开发者签名和公证。校验和只能确认文件一致，不能代替安全审计。只在确认来源可信、文件未被篡改且接受风险后继续；也可以退出并等待公证版。

  1. 苹果芯片下载 arm64，Intel 下载 x86_64。还需单独安装兼容本机的官方 Codex 客户端并登录。
  2. 先退出旧版额度面板，再打开 DMG，将应用拖到 Applications（应用程序），替换旧版。不要从磁盘映像直接运行。
  3. 尝试从“应用程序”打开。若提示无法验证开发者或未公证，先关闭警告，再到 Apple 菜单 → 系统设置 → 隐私与安全性 → 安全性，查看是否有对应项目的“仍要打开”，核实名称后自行决定授权。系统可能再次要求确认。
  4. 面板还需要 Node.js 运行组件，系统提示中名称为 node。主程序获准打开不代表组件已获准。若 node 被拦截，请先关闭提示，再按上一步核对该组件；不要误授权其他同名程序。
  5. 处理系统提示后，回到面板点击“重新连接”。若误将组件移到废纸篓，请退出工具并重新安装完整包，不要下载来历不明的 node。

使用中出现问题

“运行组件无法启动”不等于 Codex 签名错误。可用“打开隐私与安全性”和“安装与授权说明”查看下一步。没有“仍要打开”选项、设备由公司管理，或系统明确提示恶意软件、将损坏电脑、文件损坏时，请停止，不要绕过安全检测；联系管理员或反馈诊断。

组件通过检查后仍连接失败：先确认官方 Codex 能正常打开，按照下方“Codex 已打开时”的步骤连接。只有缺少端口时才需要确认重启；不愿授权自动化时可手动退出 Codex 再重连。不要授予“完全磁盘访问”“辅助功能”等无关权限。诊断文件不会自动上传，提交前请检查内容。

请勿关闭 Gatekeeper、关闭 SIP、批量删除隔离属性或自行重签名。升级后系统可能重新检查。当前仍需真实 Mac 账号验收。

安裝與首次開啟

此測試版未經 Apple 開發者簽署及公證。校驗和不等於安全審計。請確認來源、檔案完整性與風險後再繼續，或等待公證版。

  1. Apple 晶片選 arm64，Intel 選 x86_64；另行安裝相容的官方 Codex 並登入。
  2. 退出舊版面板。開啟 DMG，將應用程式拖到 Applications，替換舊版；不要從磁碟映像執行。
  3. 嘗試開啟後若遭系統阻擋，關閉警告，前往 Apple 選單 → 系統設定 → 隱私權與安全性 → 安全性，核對該項目是否提供「強制打開／仍要開啟」。確認來源後自行決定是否允許。
  4. 內附的 Node.js 元件會以 node 顯示，可能需要另外確認。請核對元件，不要授權其他同名程式。完成後回面板按「重新連線」。
  5. 若誤刪元件，請退出工具並重新安裝完整套件。不要停用 Gatekeeper、SIP，或批次移除隔離屬性。

沒有允許選項、企業管控、明確惡意軟體或損壞警告時請停止並聯絡管理員。元件檢查通過後仍失敗，請按下方「Codex 已開啟時」的流程操作。缺少連線埠時才需要確認重新啟動，也可手動退出再連線。診斷檔不會自動上傳，送出前請檢查；不需要授予完整磁碟存取等無關權限。

Codex 已打开时 / Codex 已開啟時 / When Codex is already open

无需先手动退出。打开面板并点击“重新连接”；有可用端口时直接连接。若提示缺少端口，先保存工作、等待任务结束，再点击“保存工作后重启并连接”并确认。取消不会关闭 Codex。系统如询问自动化权限，请核对是本工具请求控制 Codex；不愿授权可取消，并手动用 ⌘Q 退出 Codex 后重连。关闭红色窗口不等于退出应用。

無須先手動結束。開啟面板並按「重新連線」；有可用連線埠時直接連線。若缺少連線埠，先儲存工作並等待任務結束，再按「儲存工作後重新啟動並連線」並確認。取消不會關閉 Codex。如系統詢問自動化權限，請核對工具與 Codex；可取消並手動用 ⌘Q 結束 Codex 後重連。

Choose Reconnect first. An existing usable port is reused. Otherwise, finish active tasks and save work before choosing Save work, restart and connect. Confirming requests a normal quit and relaunch; cancellation or timeout never force-kills Codex. Review any macOS Automation prompt for the exact companion and Codex. Alternatively, decline permission and manually quit Codex with Command-Q before reconnecting. Closing its window is not quitting.

升级 / 升級 / Upgrade: Exit the old companion, replace the app in Applications, eject the DMG, and open the installed app. Confirm version 0.4.6-alpha.1 in the lower-left corner. Settings are retained.

下次如何打开 / 下次如何開啟 / Open next time

安装是将应用拖入“应用程序”，不是反复双击 DMG 内的图标。以后从 Finder → 应用程序 → Codex Quota Sidebar 打开；可拖到 Dock 保留入口。“关于项目”内可在 Finder 中显示应用。关闭窗口仍在菜单栏后台运行；“退出软件”才会退出。

安裝是將程式拖入「應用程式」，而非反覆開啟 DMG 內的圖示。之後從 Finder → 應用程式開啟，也可保留於 Dock。「關於專案」可在 Finder 中顯示應用程式。關閉視窗仍在選單列執行；「結束軟體」才會退出。

Drag the app into Applications to install it. Next time open it from Finder > Applications, or keep it in the Dock. About project includes Show application in Finder. Closing the window leaves the menu-bar companion running; Exit software quits it. Disk-image or translocated launches show installation instructions instead of being treated as installed.

端口校验 / 連線埠驗證 / Port validation: 官方 Computer Use 辅助进程可能与主进程共同持有端口。0.4.4 会核对固定路径、父子关系、应用标识和 OpenAI 签名，不需要关闭 Computer Use。官方輔助程序共同持有連線埠時仍須通過上述驗證。A co-owning official Computer Use helper is accepted only after exact-path, direct-parent, bundle-ID and OpenAI signature checks. Unknown owners and non-loopback listeners remain blocked. If blocked, export diagnostics with the displayed error code; do not disable security checks.

Install and open safely

Experimental, not Developer ID signed or notarized. Checksums establish file consistency, not a security audit. Continue only if you trust the source and accept the risk, or wait for a notarized version.

  1. Choose arm64 for Apple Silicon or x86_64 for Intel. Install a compatible official Codex client separately and sign in.
  2. Exit the previous companion, open the DMG and drag the app to Applications. Replace the old app; do not run from the disk image.
  3. Try opening it first. For an unidentified-developer/unnotarized warning, dismiss the alert. In Apple menu → System Settings → Privacy & Security → Security, check for Open Anyway for the exact item. Authorize only after verifying its origin.
  4. The bundled Node.js runtime appears as node. It can require a separate decision even after the app opens. Verify the item, handle the system prompt, then return and choose Reconnect.
  5. If the runtime was moved to Trash, exit and reinstall the complete package. Do not fetch a random replacement executable.

If no approval option exists, the device is managed, or macOS reports malware, damage or tampering, stop and seek help. Never disable Gatekeeper/SIP, remove quarantine in bulk or re-sign files. Runtime startup failure is not proof of a Codex signature error. Once the runtime works, follow the running-client workflow above. Restart is only required when a usable port is missing. No unrelated Full Disk Access or Accessibility permission is required. Review exported diagnostics before sharing; there is no automatic upload.
