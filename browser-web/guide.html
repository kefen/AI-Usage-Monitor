AI Usage Monitor

by KEFEN · Chrome · 0.6.0

这是独立的网页内嵌版，不是旧版 Chrome 侧边面板。不需要安装桌面软件、注册辅助程序或运行 PowerShell。从项目的 Chrome Release 下载安装。

第一次使用

  1. 将测试 ZIP 解压到一个固定文件夹，不要直接在 ZIP 内运行。
  2. 打开 chrome://extensions，启用“开发者模式”，点击“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。
  3. 打开并登录 ChatGPT 网页。已经打开的页面请刷新一次，并展开网页左侧栏。
  4. 左侧栏底部会出现“AI Usage Monitor”。点击标题收起后仍能看到周余；下次打开沿用折叠偏好。标有“上次读数”的数值来自刚才读取的官方页面，不代表实时返回。首次读取可能短暂展开官方用量菜单，读取完会还原；不会使用重置额度或购买额度。

按钮与数据

  • 刷新读数：读取当前网页账户的官方用量菜单。若你正在操作其他菜单，请先将其关闭。
  • 展示内容：勾选或取消项目，立即保存；不修改桌面软件设置。底部可选择语言和外观；默认跟随系统，也可手动指定。
  • 读取完整用量：在新标签页打开官方“设置 → 用量”。确认账号和工作区无误，在其左侧栏点击“确认同账号，带回读数”，便会返回原聊天标签页。只带回官方明确显示的项目；若原标签页已刷新，请从该页重新开始。
  • 点击插件工具栏图标：展开或收起面板。官方左侧栏折叠时，本版不会强行展开或遮挡它。

准确性与隐私边界

  • 这是 Codex / Work 等共享额度，不是独立的 Codex 专属额度。
  • 只显示官方可见的套餐、每周剩余、额度余额（保留小数）、明确给出的本月 Token、重置次数和重置提示。不把消息数或额度换算成 Token。
  • 当前 5 小时额度、历史 Token 及购买/续费日期没有验证来源，展示设置中明确标为不可用。
  • 每周读数跟随网页导航中的官方描述；快速菜单读数保留 60 秒，确认带回的读数最多保留 5 分钟。“读取于”表示当前显示数据中最早的页面读取时间，不是服务器刷新时间。
  • 账号菜单打开后，为避免串号，面板清空原有读数。完成账号或工作区切换后点击“刷新读数”。
  • 只保存展示偏好，不持久化用量。不读取 Cookie、密码、聊天内容或本机 CLI 账户，不向我们的服务器发送数据。

排查与卸载

没有面板：确认网址是 https://chatgpt.com/，已登录、已展开左侧栏；在扩展管理页检查已启用，再刷新网页。本版只适配已验证的新网页侧栏结构，旧版结构不强行注入。

数据为空：先用官方用量按钮确认账户确实有该项数据，再点击“刷新读数”。“--”不等于 0。出现其他官方菜单时，插件不会替你关闭。

每天最多向 GitHub 检查一次版本。发现新版会在工具栏图标和卡片底部提示；用量读数跟随网页变化，不定时刷网页。升级：覆盖同一解压文件夹，点击扩展管理页的“重新加载”，再刷新网页。卸载：在扩展管理页移除此扩展；不会移除桌面软件或旧插件。

安裝及首次使用

  1. 將 ZIP 解壓縮至固定資料夾，在 chrome://extensions 開啟開發人員模式，載入含 manifest.json 的資料夾。
  2. 登入 ChatGPT、重新整理網頁並展開側邊欄。面板會顯示在底部，不需安裝桌面工具。
  3. 收合時保留週餘；「上次讀數」表示目前官方頁面不再顯示該值。「顯示內容」可調整項目、語言與外觀。變更自動儲存。

讀數只取自目前網頁帳戶的官方用量區域。不讀取 Cookie 或聊天內容；網頁沒提供的數據不會推算。切換帳戶後請重新讀取。

Installation and first use

Extract the ZIP, open chrome://extensions, enable Developer mode, choose Load unpacked and select the directory containing manifest.json. Sign in at chatgpt.com, reload existing tabs, and expand the website sidebar.

Refresh usage reads the official usage menu and restores only the menu it opened. Collapsed mode keeps weekly remaining visible. Last read marks a recent value that is no longer visible in the official source. Display choices saves local preferences. Read full usage opens the official overview in a separate tab. Verify the account and workspace, then choose “Same account: bring readings back” in its sidebar to return the visible figures to the original chat. This is shared Codex / Work allowance, not Codex-only usage. Token totals and unsupported dates are never estimated.

No desktop companion or native-host registration is required. Only preferences are persisted; no cookies, credentials, chat text or usage telemetry are collected. Opening the profile menu clears the readout; explicitly read again after switching accounts or workspaces. Menu readings expire after 60 seconds; a confirmed overview snapshot lasts up to five minutes. The card is at the bottom of the website sidebar. The GitHub ZIP checks for versions daily; download, replace and reload when notified. It never silently installs code.
